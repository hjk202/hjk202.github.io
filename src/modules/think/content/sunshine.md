# 一个人的教室

今天天气很好，好到让人想原谅所有迟到的事。

午饭吃得很饱，胃里暖烘烘的，像揣着一只刚晒过太阳的猫。我推开教室后门的时候，午休还没结束，整间屋子空着，只有阳光先到了。它从靠窗那排桌子一路铺过来，铺过椅背、摊开的笔记本、半截粉笔，最后停在我脚边，像在等我坐下。

我坐在一个人的教室里。

风把窗帘吹起来一点，又放下。树影在桌面上轻轻晃，像有人隔着很远的地方翻书。黑板擦得不太干净，左上角还留着上一节课的公式，粉笔灰在光里慢慢飘，飘得比时间还慢。我忽然觉得，吃饱了、晒着太阳、没有人在旁边说话，也是一件很奢侈的事。

我本来想写点什么。笔帽拔开，又合上。这样的下午不适合赶路，也不适合把心事写得工工整整。我只把下巴搁在手背上，听走廊尽头传来很远的笑声，听头顶风扇偶尔转一下，听自己的呼吸慢慢和阳光一个频率。

教室很大，我只有一个人。  
可奇怪的是，一点也不空。

阳光从桌角挪到我的袖口，又从袖口挪到指尖。像有人轻轻拍了拍我，说：不急，今天天气很好。

我点点头，在心里回了一句：是啊，吃得也很饱。
